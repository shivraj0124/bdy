# Birthday Surprise ❤️
```
npm install
npm run dev
```
- Edit names, messages, photos, music, candle count in `src/config.js`.
- Photos: put files in `public/photos/` and use `/photos/1.jpg`. Music: put `music.mp3` in `public/`.
- Colors: `tailwind.config.js`. Deploy: `npm run build` → upload `dist/` (Netlify/Vercel).
